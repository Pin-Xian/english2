# 單字練習本

英文單字練習網頁。每個單字都搭配例句，用瀏覽器內建語音朗讀發音。

## 使用流程

1. **學習**：一次看一個單字和它的例句，用「← 上一個／下一個 →」切換。每個字可以標記「✓ 記得」或「✗ 不熟」。
2. **測驗**：讀過的字會自動排進複習。題型有英選中、中選英、聽音選義、例句填空、拼字。答對一次，下次測驗就排得更晚（1→3→7→14→30… 天）；答錯就標成不熟，隔天再考。
3. 連續答對 3 次以上，這個字就算「已學會」。

- 用 GitHub Pages 發布，開過一次後可離線使用
- 學習紀錄存在各裝置的瀏覽器中，可在「單字庫」匯出／匯入備份
- 部分例句來自 Tatoeba（CC-BY 2.0 FR），中文已轉成台灣繁體
